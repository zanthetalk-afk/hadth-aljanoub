# موقع شركة حدث الجنوب التجارية

موقع عربي RTL متجاوب، جاهز للنشر على GitHub Pages.

## الملفات
- `index.html` الصفحة الرئيسية
- `styles.css` التصميم والتجاوب
- `script.js` القائمة، فلترة الأعمال، ونموذج واتساب
- `assets/` ضع فيه صور أعمال الشركة والشعار

## التشغيل
لا يحتاج الموقع إلى Node.js أو قاعدة بيانات. افتح `index.html` محلياً أو ارفعه مباشرة إلى مستودع GitHub.

## النشر على GitHub Pages
1. أنشئ Repository جديداً في GitHub.
2. ارفع جميع الملفات إلى الفرع `main`.
3. افتح Settings → Pages.
4. اختر Source = Deploy from a branch.
5. اختر `main` ثم `/ (root)` ثم Save.
6. سيظهر رابط الموقع بعد اكتمال النشر.

## مهم قبل الإطلاق
- استبدل صور Unsplash التجريبية بصور أعمال الشركة الحقيقية.
- أضف الشعار الرسمي إن وجد.
- راجع رقم الهاتف وبيانات التواصل.
- يمكن إضافة نطاق خاص لاحقاً من إعدادات GitHub Pages.
